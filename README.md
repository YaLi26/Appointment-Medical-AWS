## Instalación y Despliegue
 
### Prerrequisitos
 
- Node.js >= 20.x
- NestJS
- AWS CLI 
### 1. Clonar e instalar dependencias
 
```bash
git clone https://github.com/YaLi26/Appointment-Medical-AWS.git
cd appointment-medical-aws
npm install
```
 
### 2. Compilar TypeScript
 
```bash
npm run build
```
 
### 3. Ejecutar pruebas
 
```bash
npm test
``
